Setup Guide — ML/CS Academic Job Market Auto-Tracker

Three steps. Under 5 minutes.

What this tracker does

Every morning at 7 AM UTC, a Google Apps Script fetches new ML/CS faculty and postdoc listings from mathjobs.org and adds them to your Job Board sheet. You set your keywords once; the board builds itself.

Step 1 — Copy the script

  1. In your Google Sheet, go to Extensions > Apps Script.
  2. Delete any placeholder code in the editor.
  3. Open the file tracker.gs included with this download and paste the entire contents into the editor.
  4. Click Save (Ctrl+S / Cmd+S). Name the project "Job Tracker" when prompted.

Step 2 — Authorize and run

  1. In the Apps Script editor, select the function setupTrigger from the function dropdown (top center).
  2. Click Run (▶). Google will ask for authorization — click "Review permissions", choose your Google account, then "Allow".
  3. You should see: "Daily trigger set: updateJobs runs every day at 7 AM UTC." in the execution log at the bottom.
  4. Now select runNow from the dropdown and click Run to fetch the first batch of jobs immediately.
First run takes 10–30 seconds. If you see "Feed returned 404" for all feeds, mathjobs may have changed their RSS URL structure — see Troubleshooting below.

Step 3 — Customize your keywords

In tracker.gs, find the FEEDS array at the top. Edit the keywords= parameter in each URL to match your target subfields.

Examples:

  • keywords=medical+imaging
  • keywords=reinforcement+learning
  • keywords=computational+neuroscience

Add or remove feed URLs as needed. Each keyword gets its own feed line.

Done. Your Job Board updates itself every morning.

Sheet structure

The tracker expects a sheet named Job Board with these columns in order:

A B C D E F G
Added Title Institution Deadline URL Status Notes

Row 1 must be the header row. The script appends new rows automatically and skips duplicates by URL.

Troubleshooting

All feeds return 404 or empty: mathjobs has occasionally changed its RSS URL. Try visiting mathjobs.org directly, searching for "machine learning", and looking for an RSS icon in the browser (or append &format=rss to the search URL). Update the FEEDS array with the working URL.

Jobs not appearing: Check the Apps Script execution log (View > Executions) for error messages. The most common cause is that the "Job Board" sheet doesn't exist or is spelled differently — the script looks for an exact match.

Trigger not firing: Go to Extensions > Apps Script > Triggers (clock icon, left sidebar). You should see a time-based trigger for updateJobs. If missing, run setupTrigger() again.
